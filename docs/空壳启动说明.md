# 智游闽韵 · 空壳启动说明

> 空壳 = 只有框架和 4 个占位页面，没有任何业务功能。
> 目录作用说明见：《项目结构与包说明.md》

## 一、前置要求

| 依赖 | 版本 | 检查命令 |
| --- | --- | --- |
| Node.js | 18.18+ | `node -v` |
| MySQL | 8.0+ | `mysql --version` |
| Docker | 可选（以后接向量库才用） | `docker -v` |

## 二、启动（4 步）

```powershell
cd C:\Users\HP\Desktop\智游闽韵\zhiyou-minyun

npm install                                # 1. 装依赖
npm run db:generate                        # 2. 生成 Prisma 客户端
npm run db:migrate -- --name init          # 3. 建表（首次会提示输入迁移名，已给 --name 则直接跑）
npm run dev                                # 4. 启动 → http://localhost:3000
```

> VS Code 里等价操作：`Ctrl+Shift+P` → `Tasks: Run Task` → 依次跑「1 · 安装依赖」「2 · 生成 Prisma 客户端」「3 · 建表迁移」「4 · 启动开发服务器」。

## 三、启动成功长什么样

```
▲ Next.js 16.3.6 (Turbopack)
- Local:  http://localhost:3000
✓ Ready in ~1.5s
```

| 地址 | 应看到 |
| --- | --- |
| <http://localhost:3000> | 入口页：智游闽韵（空壳），两个链接 |
| <http://localhost:3000/home> | C 端首页（占位） |
| <http://localhost:3000/b/dashboard> | B 端看板（占位） |
| <http://localhost:3000/api/health> | `{"ok":true,"db":"up","counts":{"users":0,"resources":0,"tags":0}}` |

`/api/health` 里 `db` 是 `up`，说明 **Next.js + MySQL 这条链路通了**，空壳就算搭好。
如果是 `down`，看返回的 `error`：多半是 `.env` 里的 `DATABASE_URL` 不对，或 MySQL 服务没起。

## 四、数据库连接

`.env`（不进 git）：

```text
DATABASE_URL="mysql://root:你的密码@localhost:3306/zhiyou"
```

库不存在时先建：

```powershell
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS zhiyou CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```
